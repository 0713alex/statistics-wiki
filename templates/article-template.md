# Article Title

## 1. Overview
介紹這個方法的目的、適用情境與重要性。

## 2. Definition
給出精確定義，並解釋重要術語。

## 3. Formula
使用 `$...$` 或 `$$...$$` 寫公式，逐一說明符號。

## 4. Assumptions
說明必要假設、為什麼重要及違反時的影響。

## 5. Example
提供標示為假設或模擬的例子，說明問題、資料與結果。

## 6. Code
提供 SAS 或 R 程式碼，解釋重要語句；不可虛構執行結果。

## 7. Interpretation
說明參數、檢定、信賴區間及實務解讀，避免無根據因果推論。

## 8. Common Mistakes
至少說明兩個常見錯誤、正確解讀及其重要性。
